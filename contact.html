Contact SafeClick AI

Thank you for using SafeClick AI. For website bugs, broken links or suggestions about the website, you can use the project's public GitHub issue tracker.

Report a website issue or share feedback on GitHub

Before sharing feedback

  • Describe the page or feature and what went wrong.
  • Do not post phone numbers, OTPs, passwords, bank details, private messages or other sensitive personal information.
  • If you share a screenshot, hide personal and financial details first.

Need to report a cyber fraud?

This website feedback route is not an emergency reporting service. If you have lost money to online financial fraud in India, call the national cyber-fraud helpline 1930 immediately and submit a report through the National Cyber Crime Reporting Portal.

Privacy

Please read our Privacy Policy. Do not include sensitive personal information in public feedback.

SafeClick AI does not currently publish a dedicated support email address. The GitHub issue tracker is a public forum, so anything posted there may be visible to others.
